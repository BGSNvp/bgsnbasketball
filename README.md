# BGSN Basketball Scoreboard

OBS overlay + controller for BGSN basketball. Completely separate from the football scoreboard.

## Pages
- **Controller:** `index.html`
- **OBS overlay (1920×1080 browser source):** `bgsn-bb-overlay.html`

All game data lives in one Firestore document, `basketball/live`, in the basketball Firebase project (`firebase-config.js`).
